🚀 Interakt WhatsApp Template Creation Guide

📋 What You Need to Create

You need to create 4 WhatsApp message templates in your Interakt dashboard for the OTP system to work:

  • registration_otp - For user registration
  • login_otp - For passwordless login
  • password_reset_otp - For password reset
  • phone_verification_otp - For phone verification

📱 Step-by-Step Template Creation

Step 1: Access Interakt Dashboard

  1. Go to https://app.interakt.ai
  2. Log in with your credentials
  3. Navigate to "Templates" section in the left sidebar
  4. Click "Create Template" or "+ New Template"

Step 2: Template Configuration

For each template, you'll need to configure:

  • Template Name: Use exact names from the list above
  • Category: Select "AUTHENTICATION"
  • Language: Select "English"
  • Header: Leave empty (optional)
  • Body: Use the message content below
  • Footer: Leave empty (optional)
  • Buttons: None needed for OTP

📝 Template Content

Template 1: registration_otp
Welcome! Your registration OTP is: {{1}}. Valid for 5 minutes. Do not share this code with anyone.

Variable: {{1}} = 6-digit OTP code

Template 2: login_otp
Your login OTP is: {{1}}. Valid for 5 minutes. If you did not request this, please ignore.

Variable: {{1}} = 6-digit OTP code

Template 3: password_reset_otp
Your password reset OTP is: {{1}}. Valid for 5 minutes. Use this to reset your password.

Variable: {{1}} = 6-digit OTP code

Template 4: phone_verification_otp
Verify your phone number. Your verification OTP is: {{1}}. Valid for 5 minutes.

Variable: {{1}} = 6-digit OTP code

Step 3: Template Creation Process

  1. Template Name: Enter exactly registration_otp (for first template)
  2. Category: Select "AUTHENTICATION"
  3. Language: Select "English"
  4. Body Text: Copy the exact message content from above
  5. Variables: The system will automatically detect {{1}} as a variable
  6. Preview: Check the preview to ensure it looks correct
  7. Submit: Click "Submit for Approval" or "Create Template"

⚠️ Important Notes

  • Exact Names: Template names must match exactly (case-sensitive)
  • Variable Format: Use {{1}} for the OTP placeholder
  • Category: Must be "AUTHENTICATION" for OTP templates
  • Approval Time: WhatsApp approval takes 24-48 hours
  • Character Limit: Keep messages under 1024 characters
  • No Emojis: Avoid emojis in authentication templates

Step 4: Repeat for All Templates

Create all 4 templates using the same process:

  1. Create registration_otp
  2. Create login_otp
  3. Create password_reset_otp
  4. Create phone_verification_otp

Step 5: Check Approval Status

  1. Go to Templates section in Interakt dashboard
  2. Check status of each template:
    • 🟡 PENDING - Waiting for WhatsApp approval
    • 🟢 APPROVED - Ready to use
    • 🔴 REJECTED - Needs modification
  3. Wait for all templates to be approved before testing

🧪 Testing Your Templates

Once all templates are approved:

  1. Visit Test Interakt API
  2. Run the API connection test
  3. Try sending a test OTP to your own number
  4. If successful, test the full registration flow

🚨 Common Issues & Solutions

  • Template Rejected: Usually due to wrong category or promotional content
  • Variable Not Working: Ensure you use {{1}} not {{otp_code}}
  • Template Not Found: Check exact spelling and case sensitivity
  • API Error 400: Template might not be approved yet

Step 6: Update Database (After Approval)

Once templates are approved, run the database setup:

  1. Visit Setup OTP Database
  2. This will update the template names in your database
  3. Test the OTP system with Test Registration

📞 Need Help?

  • Ensure your WhatsApp Business account is verified
